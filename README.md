# 📊 Power BI Sales Analytics Dashboard

An interactive and comprehensive **Power BI Sales Analytics Dashboard** designed to analyze sales performance, customer behavior, product performance, regional sales, and overall business growth.

This project contains multiple interconnected dashboard pages built in Power BI to transform raw sales data into meaningful and actionable business insights.

---

## 🚀 Project Overview

The objective of this project is to analyze sales data and create an interactive business intelligence dashboard that helps management understand:

- Overall sales and revenue performance
- Monthly and quarterly sales trends
- Product performance
- Customer behavior
- New vs Repeat Customers
- Customer Lifetime Value (CLV)
- Purchase Frequency
- RFM Analysis
- Customer Churn
- Regional / State-wise performance
- Business growth opportunities

The dashboard allows users to interact with the data using filters, slicers, charts, KPIs, and navigation buttons.

- Revenue Growth

---

### 2. Sales Performance Analysis

This page focuses on understanding sales performance over time.

**Analysis includes:**
- Monthly sales
- Quarterly sales
- Sales trends
- Revenue growth
- Highest sales period
- Daily sales performance

---

### 3. Product Analysis

Analyzes product-level sales performance.

**Key insights:**
- Top-performing products
- Low-performing products
- Product-wise revenue
- Product contribution to total sales
- Category performance

---

### 4. Customer CLV Analysis

Provides insights into customer purchasing behavior.

**Analysis includes:**
- Total customers
- New customers
- Repeat customers
- Purchase frequency
- Customer contribution
- Customer Lifetime Value (CLV)

---

### 5. RFM Analysis

Customer segmentation is performed using **RFM Analysis**.

RFM stands for:

- **Recency** – How recently a customer purchased
- **Frequency** – How frequently a customer purchases
- **Monetary** – How much a customer spends

RFM analysis helps identify different customer segments and understand customer purchasing behavior.

---

### 6. Churn & Customer Insights

This section focuses on customer retention and identifying customers who may have stopped purchasing.

**Analysis includes:**
- Customer churn
- Inactive customers
- Customer retention
- Customer purchasing patterns
- Potential retention opportunities

## 🧹 Data Cleaning & Transformation

Before creating the dashboard, the raw dataset was cleaned and transformed.

The data preparation process included:

- Removing duplicate records
- Handling missing values
- Removing unnecessary columns
- Standardizing data formats
- Correcting inconsistent values
- Creating calculated columns
- Creating required date fields
- Preparing data for analysis

Power Query was used for data transformation and preparation.
